# Security and privacy

PMO is designed so public source code and private memory are separate. Do not open issues or pull requests containing private vault data, access tokens, chat exports, private Drive links, or confidential workplace material.

The updater only owns files declared by the deployed system manifest. Canonical Data paths are protected from system deployment. Runtime indexes are intentionally placed outside the synchronized vault.

Report security vulnerabilities privately to the repository owner rather than publishing exploit details in a public issue.
