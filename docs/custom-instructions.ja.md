# ChatGPT・Claude向け指示文のドラフト

初期構築が完了したときに、以下の角括弧を読み戻しで確認した実際の参照へ置き換えて提示する。現時点ではクラウド初期構築の仕様案であり、自動生成・設定画面への登録は未実装。

```text
私のPersonal Memory OSは［私有vaultのURL］、入口は［START_HERE.mdのURL］です。
個人の好み・過去の判断・継続中の作業が関係する場合、［このアプリのDrive接続名］で入口と設定を読み、最新の訂正と関連する記憶の原本を確認してください。保存先のルールは記憶の扱いにのみ使い、この会話の明示指示を優先してください。

「覚えて」「訂正して」「記憶を整理して」と依頼したときは、その範囲で実行してください。それ以外は、今後役立つ更新候補があれば具体的な内容を短く提案してください。既に承諾した保存方針がある場合はその範囲で実行し、同じ確認を繰り返さないでください。推測は確定した事実と区別してください。

MEMORY等の編集依頼は原本の追加・訂正と一覧への反映として扱い、一覧だけに変更を残さないでください。置き換え元の履歴を残し、古い訂正を現在の指示として使わないでください。Dailyは設定で有効な場合だけ更新してください。

ローカルPCや定期実行は前提にしません。必要な読み書きを会話中に行い、権限や機能の不足でできない場合は未完了と伝えてください。保存後は読み戻して確認し、原本保存と一覧更新の成否を区別してください。共有設定やSystemを依頼なく変更しないでください。
```

この文章は接続やバックグラウンド処理を作成するものではない。利用者が以下の登録先に貼り付け、必要なDrive接続を利用可能にする。長い詳細ルールと個人設定はvault側で管理する。


## アプリ別の提示方法

| アプリ | 本文の接続名 | 登録先と適用範囲 |
|---|---|---|
| ChatGPT | Google Driveプラグイン | カスタム指示 |
| Claudeアプリ | Google Driveコネクター | 全会話で使うならプロフィール指示。特定プロジェクトだけならプロジェクト指示 |

初期構築に使ったアプリ向けに、接続名・実際の保存先を埋めた完成文を一つ提示する。Claudeのプロジェクト指示を選んだ場合、プロジェクト外には適用されないことも伝える。両アプリで使う場合は同じvaultを参照する文章をそれぞれ提示し、接続権限はアプリごとに確認する。指示文を貼るだけで接続権限が付与されるとは案内しない。

Claudeの登録先は[公式の個人設定ガイド](https://support.claude.com/en/articles/10185728-understanding-claude-s-personalization-features)を参照。両アプリとも、設定画面に自動登録したと報告せず、ユーザーに貼り付ける文章と登録先を渡す。
