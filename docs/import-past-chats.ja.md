# 過去のチャットを取り込む

PMO を入れる前のチャットにも、好みや決めたこと、訂正した内容が残っています。それを PMO に取り込む方法です。取り込みはチャットごとに行います。

## 準備

- PMO の初期設定が終わっていること
- 取り込みに使うアプリで、PMO の入口（カスタム指示など）を設定してあること

入口の設定は、README の「[始め方](../README.ja.md#始め方)」を見てください。

## 手順

1. 取り込みたい過去のチャットを、そのチャットを作ったアプリで開きます。
2. 次のプロンプトを、そのチャットに送ります。
3. AI が、登録した内容を分野ごとに報告します。内容を確かめ、違っていれば「それは違う」と訂正します。

```text
このチャットの内容をPMOに登録してください。

まずGoogle DriveのSTART_HEREを読み、最新のPMOルールに従ってください。
このチャット全体から、今後も再利用価値のある事実・好み・決定・プロジェクト情報・修正事項を抽出し、適切なCanonical Recordへ保存してください。

- 会話全文は保存せず、重要情報だけを整理してください。
- 各記録には分野（scope）を付けてください。すべての会話で必要なものだけglobalにし、それ以外は既存の分野を使い、合うものがなければ新しい分野を作ってください。
- 私がはっきり言ったことと、AIの推測・提案は区別し、推測を私の事実として保存しないでください。
- 時間が経つと変わりうる情報は「いつ時点の情報か」を本文に書いてください。
- 既存情報との重複・矛盾も確認し、必要ならCorrection Protocolに従ってください。

保存後、何をPMOに登録したか（分野ごと）を簡潔に教えてください。
```

## 取り込まれるもの・取り込まれないもの

| 取り込まれる | 取り込まれない |
|---|---|
| 事実、好み、決めたこと、進行中のプロジェクト、訂正 | 会話の全文、その場かぎりのやりとり |
| はっきり言ったこと | AI の推測や提案（あなたの事実としては保存しない） |

時間が経つと変わる情報（「今は〜を使っている」など）には、いつ時点の情報かが書き込まれます。

## うまくいかないとき

- **「START_HERE を読めない」と言われる**：そのアプリで Google ドライブが接続されているかを確かめます。
- **同じ内容が二重に登録された**：「記憶を整理して」と頼むと、重複をまとめる提案が出ます。
- **登録後すぐに一覧（`MEMORY.md` など）に出ない**：一覧は自動では更新されません。「一覧を更新して」と頼んでください。

取り込みの指示は、初期設定の手順書（[`pmo-setup`](../skills/pmo-setup/SKILL.md)）の最後でも案内されます。
